# SPL Monitor: updates and downloads

SPL Monitor is an SPL meter focused on ease of use and noise-limit compliance, by Durham Media Group.

This repo holds no source code. It carries two things:

- **Downloads.** Each release is on the [Releases](https://github.com/Dylland/SPL-Monitor-Updates/releases) page as a Mac DMG.
- **`latest.json`.** SPL Monitor reads this small file at launch and every 6 hours to see whether a newer build is out. The check sends nothing about you or your Mac.
